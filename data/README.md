# Входные данные

Тебе доступны три файла в формате Parquet.

1. `train.parquet` — обучающая выборка, 497 673 строки.

Каждая строка — пара «запрос — объявление»: пользователь искал по этому запросу и выбрал это объявление. В строке есть признаки запроса (колонки `search_*`) и признаки объявления (колонки `item_*`).

Пример:

`search_query`: "автоподбор"

`search_infm_params_text`: "Рейтинг пользователя 4 звезды и выше"

`item_title_raw`: "Автоподбор Разовый осмотр автомобиля"

Это значит, что пользователь искал «автоподбор» с фильтром по рейтингу и выбрал объявление «Автоподбор Разовый осмотр автомобиля».

2. `benchmark_queries.parquet` — 2 452 запроса без разметки. Для них нужно подготовить ответ.

Колонки:

- `query_id` — идентификатор запроса;
- признаки запроса в том же формате, что в `train.parquet`.

3. `benchmark_items.parquet` — корпус из 189 212 объявлений, среди которых нужно искать.

Колонки:

- `item_id` — идентификатор объявления;
- признаки объявления в том же формате, что в `train.parquet`.

Все подходящие объявления для запросов бенчмарка есть в этом корпусе.

Файлы можно скачать одним архивом по ссылке: https://disk.yandex.ru/d/sNhfo0YOjGtufg

#### Признаки запроса

| Поле | Описание |
| --- | --- |
| `search_query` | текст поискового запроса |
| `search_location_id` | идентификатор локации, в которой выполнялся поиск |
| `search_is_delivery_search` | флаг поиска с доставкой (0/1) |
| `search_infm_params_text` | фильтры поиска в текстовом виде, например «Вид услуги Красота, здоровье»; может быть пустым |
| `search_category` | категория, в которой выполнялся поиск |

#### Признаки объявления

| Поле | Описание |
| --- | --- |
| `item_id` | идентификатор объявления |
| `item_title_raw` | заголовок объявления |
| `item_description_raw` | описание объявления |
| `item_infm_params_text` | параметры объявления в текстовом виде: вид услуги, тип услуги и т. п. |
| `item_category_id` | категория объявления |
| `item_microcat_id` | подкатегория объявления: более детальное деление внутри категории |
| `item_price` | цена |
| `item_rating` | рейтинг по отзывам |
| `item_rating_reviews_count` | количество отзывов |
| `item_location_id` | идентификатор локации объявления |
| `item_latitude`, `item_longitude` | координаты объявления |
| `item_is_phone_hidden` | флаг: телефон скрыт |
| `item_is_message_forbidden` | флаг: сообщения запрещены |
